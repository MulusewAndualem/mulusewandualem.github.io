# Mulusew Andualem — Personal Website

A responsive, professional one-page personal website designed for free hosting.

## Files
- `index.html` — website content
- `css/style.css` — design and responsive layout
- `js/script.js` — mobile menu and year
- `assets/logo.svg` — simple logo
- `assets/cv.pdf` — placeholder file location for your CV

## Before publishing
1. Replace `your.email@example.com` in `index.html` with your real email.
2. Replace the LinkedIn link and username.
3. Add your actual CV as `assets/cv.pdf`.
4. Add your professional photo by replacing the initials circle if desired.
5. Update the experience and publication sections with verified details.

## Publish free with GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a **public** repository named exactly `YOURUSERNAME.github.io`.
3. Upload all files from this folder, keeping the folders intact.
4. Open the repository's **Settings → Pages**.
5. Under deployment/source, choose **Deploy from a branch**, select `main`, and `/ (root)`.
6. Save.
7. Your site will be available at `https://YOURUSERNAME.github.io`.

There is no trial period for GitHub Pages hosting. A custom `.com` domain is optional and normally costs money.
